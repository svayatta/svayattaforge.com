# svayattaforge.com

The website of [Svayatta Forge](https://github.com/svayatta): sovereign AI tools, open source under Apache 2.0, built by Charioteer Consulting Ltd.

A single static page served by GitHub Pages at https://svayattaforge.com. No build step, no framework, no tracking. Edit `index.html` and push to `main`.

- `index.html`: the page, with inline CSS and the anvil mark as inline SVG
- `favicon.svg`, `favicon.ico`, `favicon-32.png`: browser icons (SVG first, ICO and PNG for Safari, older browsers, and search results)
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `site.webmanifest`: home-screen icons for iOS and Android
- `og.png`: the 1200 × 630 share image
- `CNAME`: the custom domain for GitHub Pages
